Nebula Builds

Cinematic Kodi skin & one-tap wizard

A minimal cinematic skin for Kodi 20–22 with six themes, plus a wizard that installs and updates builds in one tap. Everything on this site is original and fully licensed for redistribution.

Install on Kodi (FireStick or any device)

  1. Install Kodi 20 (Omega) or newer.
  2. Before anything else: open Settings → System → Add-ons and toggle Unknown sources ON. Skip this and the next step will fail.
  3. Open Settings → Add-ons → Install from zip file and paste this URL:
https://stix26.github.io/nebulabuilds/repository.nebulabuilds.zip

Kodi installs the Nebula Builds repository. Then open Settings → Add-ons → Install from repository → Nebula Builds and install Nebula Wizard and the Nebula skin. Open the wizard — on first run it prompts you to pick a build, downloads it, verifies its checksum, and installs it.

Alternative single-step link: https://stix26.github.io/nebulabuilds/wizard.zip
