## Beginner Walkthrough — Kodi Install to Entering the URL

Follow this with the **Lady Guin** wizard and install the **Toy Story** build. It is the easiest
option for someone new to Kodi.

### 1. Install Kodi

<ul>
    <li>Download Kodi from the official site: <code>https://kodi.tv/downloads</code></li>
    <li>Install it like any other app on your device (Windows, macOS, Android TV box, Fire Stick, etc.)</li>
    <li>Open Kodi once and let it finish its first-time setup.</li>
</ul>

### 2. Allow installations from unknown sources

<ul>
    <li>Open <b>Settings</b> (gear icon, top left)</li>
    <li>Go to <b>System</b> &gt; <b>Add-ons</b></li>
    <li>Toggle <b>Unknown sources</b> to ON and confirm with <b>Yes</b></li>
</ul>

### 3. Add the source (this is the part where you enter the URL)

<ul>
    <li>Go back into <b>Settings</b> and open <b>File Manager</b></li>
    <li>Select <b>Add source</b></li>
    <li>Click the empty field (<b>&lt;None&gt;</b>) to bring up the keyboard</li>
    <li>Enter the URL exactly as written:</li>
</ul>

<pre><code>https://the666mafia.github.io/the666mafia</code></pre>

<ul>
    <li>Press <b>OK</b>, then name the source (e.g. <b>mafia</b>) and press <b>OK</b></li>
</ul>

### 4. Install the repository

<ul>
    <li>Go to <b>Settings</b> &gt; <b>Add-ons</b></li>
    <li>Select <b>Install from zip file</b></li>
    <li>Choose the source you just added (<b>mafia</b>)</li>
    <li>Install <code>repository.the666mafia-1.x.zip</code> and wait for the "repository installed" notification</li>
</ul>

### 5. Install the Lady Guin wizard

<ul>
    <li>Still in <b>Add-ons</b>, select <b>Install from repository</b></li>
    <li>Select <b>the666mafia</b></li>
    <li>Open <b>Program add-ons</b></li>
    <li>Install the <b>Lady Guin wizard</b> (choose the <b>Omega</b> wizard for Kodi 21.x or the <b>Nexus</b> wizard for Kodi 20.x)</li>
</ul>

### 6. Install the Toy Story build

<ul>
    <li>Open <b>Add-ons</b> &gt; <b>Program add-ons</b> and launch the <b>Lady Guin</b> wizard</li>
    <li>Open the <b>Build Menu</b></li>
    <li>Select <b>Toy Story</b> and confirm <b>Install</b></li>
    <li>Wait for the build to download and install</li>
    <li>When asked, let Kodi force-close, then reopen it — the build will be loaded</li>
</ul>

## The Other Two Recommended Wizards

### NXTFlix

<ul>
    <li>Add the source <code>https://blry12.github.io/nxtflix</code> in File Manager (same steps as above)</li>
    <li>Install from zip: <code>repository.nxtflix-1.x.zip</code></li>
    <li>Install from repository: <b>NXTFlix</b> &gt; <b>Program add-ons</b> &gt; <b>NXTFlix</b></li>
    <li>Note: the main NXTFlix build needs a debrid service (e.g. Real-Debrid) to play most content</li>
</ul>

### BReeZz

<ul>
    <li>Add the source <code>http://breezz1.com/repo</code> in File Manager</li>
    <li>Install from zip: <code>repository.breezz-x.x.zip</code></li>
    <li>Install from repository: <b>Breezz Repo</b> &gt; <b>Program add-ons</b> &gt; <b>Breezz 19 Wizard</b></li>
</ul>

## Nebula Builds Repository

### Instructions for installing this repository without a source:

<ul>
    <li>Download the Nebula Builds repository</li>
    <li>Open Kodi Settings and go to Add-Ons. Then select "Install from zip file"</li>
    <li>Navigate to where you saved the above repository zip file and select to install</li>
</ul>

### Instructions for adding this repo's source:

<ul>
    <li>Open the Kodi File Manager</li>
    <li>Select "Add source"</li>
    <li>The path for the source is <code>https://stix26.github.io/nebulabuilds/</code></li>
</ul>

### Instructions for installing the Nebula Wizard:

<ul>
    <li>Open Kodi Settings and choose Add-Ons. Then select "Install from repository"</li>
    <li>Select "Nebula Builds"</li>
    <li>Navigate to the "Program add-ons" section in the repo, and you'll find the Nebula Wizard add-on. From there, install Nebula Wizard.</li>
</ul>
